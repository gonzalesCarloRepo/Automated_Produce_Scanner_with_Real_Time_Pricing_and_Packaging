# Automated Produce Scanner with Real-Time Pricing and Packaging

A Raspberry Pi-based automated retail prototype that integrates
computer vision, machine learning, weight measurement, real-time
pricing, barcode generation, and automated packaging.

## Overview

The Automated Produce Scanner with Real-Time Pricing and Packaging
is a self-service retail prototype developed as a Computer Engineering
capstone project.

The system uses a Raspberry Pi 4 Model B as its central processing
unit and integrates a Raspberry Pi Camera Module V2, Edge Impulse
machine-learning inference, load-cell-based weight measurement,
a local pricing database, LCD display, thermal barcode printer,
and an automated sealing mechanism.

The prototype is designed to identify selected produce, determine
its weight, calculate its price in real time, generate a barcode
receipt, and package the produce automatically.

## Features

- Vegetable image detection and classification
- Real-time weight measurement
- Real-time price calculation
- Local price database
- LCD information display
- Barcode receipt generation
- Automated bag sealing
- Assorted-vegetable detection
- Administrator price management
- Offline machine-learning inference
