Automated Produce Scanner with Real-Time Pricing and Packaging is an embedded retail automation prototype built around a Raspberry Pi 4 Model B. The system combines computer vision and Edge Impulse-based machine learning to identify produce, a load cell and HX711 module to measure weight, and a local database to calculate real-time pricing. The resulting transaction information is displayed through an LCD and printed as a barcode label. After user confirmation, an automated linear-actuator-driven sealing mechanism packages the produce. The system demonstrates the integration of computer vision, edge AI, embedded systems, sensor interfacing, database management, and electromechanical automation in a single retail-oriented prototype.
